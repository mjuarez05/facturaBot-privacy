Política de Privacidad

FacturaBot es un bot de WhatsApp utilizado para la emisión de comprobantes fiscales y gestión de facturación.

Información que recopilamos

Podemos recopilar la siguiente información proporcionada voluntariamente por el usuario:

  • Número de teléfono
  • Datos fiscales (CUIT, tipo de comprobante, importes)
  • Mensajes enviados por WhatsApp

Uso de la información

La información se utiliza exclusivamente para:

  • Emitir comprobantes fiscales
  • Responder solicitudes del usuario
  • Cumplir obligaciones legales y fiscales

Almacenamiento y seguridad

Los datos se almacenan de forma segura y no se comparten con terceros, salvo cuando sea necesario para cumplir con obligaciones legales.

Terceros

FacturaBot utiliza servicios de terceros como WhatsApp (Meta Platforms Inc.) y servicios fiscales oficiales.

Eliminación de datos

El usuario puede solicitar la eliminación de sus datos escribiendo a: contacto@facturabot.local

Contacto

Para cualquier consulta relacionada con esta política de privacidad, puede contactarnos en:
contacto@facturabot.local
